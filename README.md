# M5Stack Hardware Repository

Welcome to the M5Stack open-source hardware repository (Blyzz-cut)! This repository contains hardware design files for M5Stack product series, including PCB designs, structural files, and KiCad libraries.

## 📁 Directory Structure

```
M5_Hardware/
├── Common/              # Common module designs (Atomic, Module, Unit types)
├── Products/            # Product designs organized by SKU
│   ├── [SKU_Name]/
│   │   ├── Footprints/        # PCB design files
│   │   └── Structures/ # 2D/3D structure files
│   └── ...
├── KiCad/              # KiCad library files
│   ├── 3D/             # 3D models
│   ├── Footprints/     # Footprint library
│   └── Symbols/        # Symbol library
└── Docs/               # Documentation
```
